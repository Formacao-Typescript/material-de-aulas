# Exemplo 2 - Tipando uma classe

Teremos a mesma ideia do exemplo 1, porém ao invés de tipar um módulo vamos
tipar uma classe. Aqui vamos ter:

1. Um arquivo `classe.js` que representa o compilado
2. Um arquivo `classe.d.ts` que representa o tipo
3. Um arquivo `uso.ts` que será o uso da classe

A ideia é mostrar como podemos definir assinaturas de tipos para classes em
arquivos de declaração
